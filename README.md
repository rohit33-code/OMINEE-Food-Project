# 🍔 OMINEE Food Project

A modern and responsive food delivery landing page built using **HTML, CSS, and JavaScript**.  
This project showcases a clean UI for a healthy meal subscription service with responsive sections, customer testimonials, pricing plans, and contact forms.

# ⚙️ Installation & Usage

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/rohit33-code/OMINEE-Food-Project.git
```

## 2️⃣ Open Project Folder

```bash
cd ominee-food
```

## 3️⃣ Run the Project

Simply open `index.html` in your browser.

---

# 🌐 Deploy on GitHub Pages

1. Push your project to GitHub
2. Go to:
   - **Repository Settings**
   - **Pages**
3. Select:
   - Branch → `main`
   - Folder → `/root`
4. Save and wait for deployment
